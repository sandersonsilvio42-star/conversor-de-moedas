# Conversor de Moedas 💵🔄

Aplicação prática de conversão de valores desenvolvida como projeto de estudo durante o curso de Desenvolvimento Full-Stack do **DevClub**.

O objetivo principal deste projeto foi consolidar os fundamentos da lógica de programação em JavaScript, focando em operações matemáticas básicas, captura de eventos do usuário e atualização em tempo real dos elementos da tela.

## 🚀 Link do Projeto
Confira a aplicação rodando: https://trademoney.vercel.app/

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação dos campos de entrada e seleção de moedas.
* **CSS3:** Estilização moderna e layout centralizado para facilitar o uso.
* **JavaScript:** Lógica de cálculo para conversão de valores e manipulação dinâmica do DOM.
